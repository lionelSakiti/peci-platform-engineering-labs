# Contribuer
1. Lire le code de conduite et rechercher les doublons.
2. Ouvrir ou choisir une issue; commenter son intention et attendre coordination.
3. Créer une branche `lab/peci-lab-XXX-description` ou `docs/description` depuis main.
4. Documenter versions, architecture, prérequis, commandes, coûts estimés, tests et nettoyage.
5. Ouvrir une PR liée à l’issue; fournir preuves de tests et limites; ne jamais commiter de secrets.
6. Obtenir une revue indépendante; corriger les observations; fusionner selon règles du dépôt.
7. Pour upstream, lire CONTRIBUTING et respecter CLA/DCO du projet cible; ne pas présenter une PR comme acceptée avant fusion.

## Definition of Done
- Sources officielles et versions épinglées.
- Reproduction par un second ingénieur, tests positifs/négatifs, mesures et nettoyage.
- Documentation accessible, données synthétiques, licences vérifiées.
- Démonstration et retour d’expérience lorsque pertinent.

## Niveaux
L1 initiation; L2 intermédiaire; L3 avancé; L4 expert; L5 spécialiste. Les niveaux sont indicatifs.
