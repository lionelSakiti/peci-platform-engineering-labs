# Taxonomie des labels
Types : intelligence, lab, meetup, upstream, governance.
Priorité : P1, P2, P3.
Difficulté : level-1 à level-5.
Domaines : backstage, gitops, kubernetes, observability, security, iac, virtualization, ai, finops.
Statuts proposés : needs-validation, ready, in-progress, blocked.
Les labels sont descriptifs; ne pas assimiler une issue ouverte à un Lab validé.
